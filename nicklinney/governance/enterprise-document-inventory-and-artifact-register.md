# Enterprise Document Inventory and Artifact Register

## Purpose

This page is the logical enterprise inventory for known, proposed, generated, implied, and reference documentation across the NickLinney.* ecosystem.

It is an artifact register, not proof that every entry currently exists as a durable repository file.

## Primary Finding

The ecosystem does not primarily suffer from a lack of documentation. It suffers from document-state fragmentation.

Key fragmentation patterns include:

- canonical documents not yet located as discrete authoritative files
- complete markdown artifacts embedded in conversations or transcript bundles
- important standards existing only as sections inside larger documents
- implied required artifacts not yet formalized as controlled records

## Status Definitions

- Uploaded source: independently located source artifact
- Uploaded conversation or source bundle: artifact exists inside a larger uploaded bundle
- Generated, not reuploaded: substantially written in chat but not independently recovered
- Composite generated document: complete document exists across multiple generated sections that should be consolidated
- Requested or generation unverified: creation requested but completed artifact not independently verified
- Proposed: explicitly recommended for future creation
- Implied required artifact: required by process, architecture, or governance but not yet separately created
- Referenced source: external evidence rather than native policy artifact
- Working concept: substantive content exists but is not yet formalized as a controlled document
