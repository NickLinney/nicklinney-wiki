## Purpose

`NickLinney.DevOps` governs the automation and delivery discipline of the ecosystem.

It is expected to define how code, infrastructure, validation, packaging, deployment, and release workflows are automated and controlled across environments.

## Scope

This module is expected to own:

- CI/CD standards
- infrastructure-as-code patterns
- deployment strategies
- build and validation workflows
- release engineering controls
- operational delivery governance
