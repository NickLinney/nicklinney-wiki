## Purpose

`NickLinney.Contracts` governs contract-first architecture across the NickLinney.* ecosystem.

Its role is to define the interfaces, schemas, compatibility expectations, versioning boundaries, and interoperability agreements that allow modules, services, and agents to collaborate predictably.

## Scope

This module is expected to own:

- interface specifications
- schema definitions
- API and protocol contracts
- compatibility guarantees
- semantic versioning relationships
- inter-module interoperability rules
