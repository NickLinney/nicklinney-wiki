# NickLinney.AutoGit

## Status

- Status: Canonical
- Canonicality: Canonical
- Origin: Wiki-native baseline artifact
- Created: July 27, 2026

## Purpose

`NickLinney.AutoGit` governs source-control discipline and repository lifecycle automation across the ecosystem.

It is expected to define branching, tagging, attribution, semantic versioning, release automation, repository hygiene, and machine-assisted Git workflows.

## Scope

This module is expected to own:

- repository lifecycle standards
- branching and merge governance
- tagging and release automation
- attribution and commit-identity rules
- semantic versioning policy
- repository hygiene controls
