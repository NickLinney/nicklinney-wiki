- Owning Module: `NickLinney.AutoGit`

## Purpose

This policy record defines how attribution should be governed for source-control activity, including future machine-assisted contribution.

## Attribution Principles

- authorship should remain inspectable
- automated assistance should not erase accountability
- release history should remain attributable across time
- identity ambiguity should be resolved through explicit policy rather than assumption

## Governance Rule

If a contribution path changes attribution semantics, that change should be treated as a governance decision rather than a tooling detail.
