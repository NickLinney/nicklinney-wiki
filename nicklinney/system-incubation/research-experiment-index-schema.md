# Research Experiment Index Schema

## Status

- Status: Canonical
- Canonicality: Canonical
- Origin: Wiki-native schema artifact
- Created: July 27, 2026
- Owning Space: `System`

## Purpose

This schema defines the minimum structure for recording concepts and experiments within the `System` incubation space.

## Minimum Fields

- concept identifier
- title
- thematic domain
- maturity status
- current owner or maintainer
- related canonical module if known
- review status
- promotion outcome if applicable
- notes

## Governance Rule

Incubating concepts should be indexable and reviewable as a population of research objects rather than as untracked fragments.

## Intended Use

This schema is intended to support:

- experiment inventory
- review scheduling
- promotion traceability
- boundary clarity between incubation and canon
