## Purpose

This guide defines the minimum viable method for preparing a capability gap report that compares SICAF strategic intent with RCMF operational reality. Its purpose is to produce a repeatable, evidence-based assessment that supports executive decisions on priority improvements, sequencing, ownership, and governance.

## Inputs

| Input | Description | Minimum standard |
| --- | --- | --- |
| SICAF reference set | Strategic objectives, required capabilities, policy intent, target-state expectations | Approved source set current as of assessment date |
| RCMF reference set | Current operating model, controls, workflows, reporting, and role assignments | Operationally validated and in active use |
| Evidence pack | Policies, process maps, logs, reports, issue registers, tool configurations, meeting decisions | Sufficient to substantiate each scored conclusion |
| Stakeholder interviews | Structured input from executive, operational, and assurance roles | Representation across decision, execution, and oversight layers |
| Prior decisions | Existing remediation commitments, roadmap items, and exceptions | Incorporated to avoid duplicate recommendations |

## Method

1. Define the comparison baseline.
2. Establish capability domains.
3. Gather evidence.
4. Score alignment.
5. Classify gaps.
6. Prioritize action.
7. Produce outputs.

## Standard Capability Domains

| Domain | Strategic question | Operational question |
| --- | --- | --- |
| Governance and decision rights | Is accountability clear at the strategic level? | Are decisions made, documented, and enforced in practice? |
| Control architecture | Are required controls defined and aligned to intent? | Are controls implemented, monitored, and evidenced? |
| Process execution | Does the target model describe repeatable workflows? | Are workflows consistent, timely, and resilient in live operations? |
| Data and reporting | Does leadership have the information needed to govern? | Is operational data complete, timely, and trusted? |
| Tooling and automation | Does the strategy assume enablement through systems? | Do tools support consistent execution and traceability? |
| Roles and capability | Are required competencies and role expectations defined? | Do teams have the capacity and skill to perform reliably? |
| Assurance and improvement | Is continuous oversight expected? | Are reviews, issue management, and corrective actions effective? |

## Analysis Structure

Each domain assessment should answer:

- What SICAF expects
- What RCMF currently does
- What evidence supports the conclusion
- What gap type exists
- What risk or performance consequence follows
- What action is recommended

## Rating Scale

| Rating | Meaning | Implementation interpretation |
| --- | --- | --- |
| 0 | Not present | No reliable practice or artifact exists |
| 1 | Ad hoc | Activity occurs inconsistently and depends on individuals |
| 2 | Defined | Process exists but is not yet consistently measured or enforced |
| 3 | Managed | Process is repeatable, evidenced, and governed |
| 4 | Optimized | Process is integrated, monitored, and improved systematically |

## Gap Typology

| Gap type | Description | Typical response |
| --- | --- | --- |
| Design gap | Strategic requirement is not translated into operating design | Define policy, process, or control structure |
| Execution gap | Design exists but is not performed consistently | Strengthen procedures, ownership, and monitoring |
| Data gap | Required evidence or reporting is incomplete or unreliable | Improve data model, reporting controls, and traceability |
| Ownership gap | Accountability is unclear or fragmented | Clarify roles, decision rights, and approval authority |
| Assurance gap | Review, challenge, or corrective action is weak | Add oversight routines, issue tracking, and control testing |

## Prioritization Logic

Prioritization should balance five factors:

| Factor | Decision rule |
| --- | --- |
| Impact | Prioritize gaps that materially affect risk exposure, service reliability, or executive visibility |
| Urgency | Prioritize issues that require near-term control stabilization or decision clarity |
| Dependency | Prioritize foundational items that unlock multiple downstream improvements |
| Sensitivity | Elevate gaps tied to regulatory, fiduciary, or board-level commitments |
| Effort | Sequence high-value, low-complexity actions early where practical |

## Decision Criteria

Recommendations are ready for approval when they:

- Close a clearly evidenced gap
- Have an identified accountable owner
- Are feasible within the expected operating model
- Improve control reliability or management visibility
- Can be tracked through measurable completion criteria

## Outputs

The minimum required outputs are:

1. A capability gap report by domain.
2. A prioritized recommendations register.
3. An executive action plan with timing, owners, dependencies, and decision points.

## Cadence

| Activity | Cadence |
| --- | --- |
| Full RCMF vs. SICAF assessment | Semiannual |
| Targeted refresh for material changes | Within 30 days of major operating or governance change |
| Action plan progress review | Monthly |
| Executive status review | Quarterly |

## Minimum Quality Standard

The report is considered fit for use when:

- Each conclusion is evidence-based
- Strategic intent and operational reality are compared in the same domain structure
- Ratings are explicit and explainable
- Recommended actions are prioritized and assignable
- Executives can approve next steps without requesting a redesign of the analysis
