## 1. Purpose

This register is the control record for tracking capability gaps, action decisions, remediation progress, and closure status across the NickLinney.Ops governance cycle. It is the primary tool for maintaining visibility of improvement work within the MVP framework.

## 2. Scope

The register covers all capability improvement items arising from formal evaluations, approved action plans, deferred actions, mitigation items, and accepted risks that require periodic review.

## 3. Register Management Standard

- Every material capability gap that requires follow-up must be entered in this register.
- Each item must have one accountable owner.
- Status must be updated at each scheduled review or when a material change occurs.
- Closed items must include a closure rationale and review date.

## 4. Status Definitions

| Status | Definition |
| --- | --- |
| Open | Item logged and awaiting action start or final planning approval |
| In Progress | Action is actively being executed |
| Pending Approval | Decision, funding, or direction is required before progress can continue |
| Deferred | Action is intentionally postponed with approval and review date |
| Closed | Outcome reviewed and no further action currently required |

## 5. Priority Definitions

| Priority | Meaning |
| --- | --- |
| High | Requires timely attention due to material operational impact or risk |
| Medium | Important improvement with manageable short-term exposure |
| Low | Desirable improvement that can be scheduled flexibly |

## 6. Register Fields

The following fields are the minimum required data set for each item.

| Field | Description |
| --- | --- |
| Register ID | Unique identifier for the item |
| Date Logged | Date the item entered the register |
| Capability Area | Capability, process, or domain affected |
| Source Reference | Originating evaluation, report, or decision |
| Gap Summary | Concise description of the issue |
| Impact | Operational consequence or risk |
| Disposition | Remediate, Mitigate, Defer, or Accept Risk |
| Action Owner | Accountable person |
| Priority | High, Medium, or Low |
| Target Date | Expected completion or next decision date |
| Status | Current state of the item |
| Success Measure | How completion will be validated |
| Latest Update | Most recent progress note |
| Closure Basis | Reason item is considered closed, if applicable |
| Next Review Date | Date of the next formal review |

## 8. Review Cadence

| Activity | Cadence |
| --- | --- |
| Register review meeting | Biweekly |

## 9. Approval and Maintenance

- The Governance Lead maintains the register.
- Capability Owners are responsible for the accuracy of updates for their assigned items.
- Closure of high-priority items, deferred items, and accepted risks should be confirmed by the approver.
