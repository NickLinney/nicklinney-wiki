## 1. Purpose

This SOP defines the minimum standard for evaluating operational capabilities and reporting the results in a consistent, decision-ready format. It supports the ECEGF closed-loop governance model by ensuring that capability gaps are identified, evidenced, rated, and communicated in a way that supports action planning.

## 2. Scope

This SOP applies to all formal capability evaluations conducted under NickLinney.Ops, including routine reviews, targeted assessments, and change-triggered evaluations.

## 3. Roles

| Role | Responsibility |
| --- | --- |
| Governance Lead | Ensures the SOP is used and reporting quality is acceptable |
| Capability Owner | Confirms scope, provides context and evidence, reviews draft findings |
| Evaluator | Conducts assessment, documents ratings, and issues report |
| Approver | Accepts report and determines whether action planning is required |

## 4. Evaluation Standard

Each evaluation must define:

- Capability being assessed
- Intended outcome or target state
- Evaluation criteria
- Evidence reviewed
- Current performance or maturity assessment
- Identified gaps, risks, and impacts
- Recommended disposition

## 5. Evaluation Process

### 5.1 Initiate

- Confirm capability scope and owner
- State the purpose of the evaluation
- Define the criteria or expected operating standard

### 5.2 Gather Inputs

Minimum inputs should include, where available:

- Existing process or workflow documentation
- Performance indicators or observable outcomes
- Prior gap reports or improvement actions
- Known risks, incidents, or stakeholder concerns

### 5.3 Assess

Evaluate the capability against its intended state and record evidence-based findings. Ratings should be simple and usable for MVP governance.

| Rating | Definition |
| --- | --- |
| Green | Capability is performing as intended with no material gap |
| Amber | Capability is partially effective or inconsistent; improvement is needed |
| Red | Capability is materially ineffective, missing, or presents significant risk |

### 5.4 Report

The evaluator must issue a concise report that includes:

| Required Reporting Element | Minimum Standard |
| --- | --- |
| Summary | Plain-language statement of overall condition |
| Scope | Capability assessed and assessment boundaries |
| Evidence | Facts, artifacts, or observations supporting conclusions |
| Rating | Green, Amber, or Red |
| Gaps | Specific deficiencies or control weaknesses |
| Impact | Operational consequence if not addressed |
| Recommendation | Action, deferment, or risk acceptance recommendation |

### 5.5 Review and Approval

- Capability Owner reviews for factual accuracy
- Approver confirms disposition of findings
- Any Amber or Red finding must be explicitly dispositioned

## 6. Required Inputs and Outputs

| Inputs | Outputs |
| --- | --- |
| Capability scope | Capability evaluation report |
| Evaluation criteria | Assigned rating |
| Evidence set | Documented gaps and impacts |
| Prior actions or baseline | Recommendation and disposition decision |

## 7. Reporting Conventions

- Findings must be specific enough to support action planning.
- Narrative should distinguish observed facts from evaluator judgment.
- Recommendations should be proportionate to impact and effort.
- If evidence is limited, the report must say so directly.

## 8. Escalation Thresholds

Escalation is required when:

- A Red finding affects a core operating capability
- There is no clear owner for remediation
- The gap presents recurring or growing operational risk
- A previously accepted action remains overdue without approved justification

## 9. Review Cadence

| Activity | Cadence |
| --- | --- |
| Standard capability review | Monthly or as scheduled by Governance Lead |
| Triggered reassessment | Upon major process, tool, staffing, or risk change |
| SOP review | Quarterly |

## 10. Approval

This SOP becomes effective upon approval by the designated approval authority. Use of alternative formats is permitted only if they preserve all required inputs, outputs, and decision elements defined here.
