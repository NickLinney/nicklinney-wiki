# Template Library

## Purpose

This space provides reusable page templates for common NickLinney.* documentation artifacts.

These templates are intended to improve consistency, authority, navigability, and long-term maintainability.

## Available Templates

- [Product Page Template](/nicklinney/templates/product-page-template)
- [Project Page Template](/nicklinney/templates/project-page-template)
- [Standard Page Template](/nicklinney/templates/standard-page-template)
- [ADR Template](/nicklinney/templates/adr-template)
- [Governance Record Template](/nicklinney/templates/governance-record-template)

## Template Use Rules

- prefer stable titles and explicit scope
- record status and authority where appropriate
- preserve separation between governance, design, operations, and implementation
- cross-link to governing documents rather than duplicating them unnecessarily
- include provenance when content originates from recovered or composite artifacts
