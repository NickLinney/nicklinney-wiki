# Canonical Source Declaration Record Standard

## Purpose

This standard defines how to declare the authoritative source for a document when multiple copies, variants, or locations exist.

## When Required

A canonical-source declaration is required when:

- a document exists in both chat and wiki form
- uploaded files and wiki pages diverge
- repository sources and published pages differ
- multiple candidate versions exist with unclear authority
- a superseding artifact is published while prior copies remain accessible

## Required Declaration Elements

Each declaration should identify:

- logical artifact title
- owning module
- designated canonical source
- non-canonical related copies
- authority making the designation
- date of designation
- reason for designation
- supersession or reconciliation notes

## Canonicality States

Suggested values include:

- Canonical
- Candidate Canonical
- Duplicate Non-Canonical
- Historical Copy
- Unresolved Conflict

## Historical Retention Rule

Declaring one copy canonical does not require destroying all others. Non-canonical copies may still be retained for provenance, comparison, or evidentiary reasons so long as their status is explicit.

## Operational Benefit

This standard prevents silent divergence and allows the wiki to preserve both authority and historical memory at the same time.
