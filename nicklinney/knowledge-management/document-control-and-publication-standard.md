# Document Control and Publication Standard

## Purpose

This standard defines the lifecycle states, publication rules, and historical-retention expectations for controlled documentation in the NickLinney.* ecosystem.

## Controlled States

### Draft

Actively being authored or recovered. Not yet authoritative.

### Reviewed

Content has received substantive review but has not yet been formally approved as canonical.

### Approved

Content is approved for use and governance reliance.

### Canonical

The designated authoritative version of a document.

### Superseded

Replaced by a newer controlled artifact but retained for historical and interpretive value.

### Deprecated

Still present for compatibility or reference but no longer recommended for new use.

### Archived

Retained for historical purposes with no expectation of active maintenance.

### Evidence-Only

Preserved as source material or provenance evidence rather than as a governing or operational document.

## Publication Rules

- No page should be assumed canonical without explicit designation.
- Recovered chat artifacts should normally begin as Draft or Reviewed.
- Superseded and archived documents should remain discoverable.
- External references should be clearly marked as non-native authority.
- When a page summarizes a larger source, the relationship to the source should be stated.

## Historical Retention Rules

- historical pages are retained unless there is a compelling confidentiality or error reason to remove them
- supersession should point forward to the replacement
- replacement pages should point backward to superseded material when relevant
- major interpretive shifts should preserve rationale, not only final outcomes

## Required Metadata Expectations

Each controlled page should eventually declare:

- title
- owning module
- document class
- status
- canonical-source status
- version or revision marker when available
- related documents

## Compliance Intent

This standard exists so the wiki can function as both a current authority space and a historical knowledge record.
